# Evidence 1 
**Data Structures and Fundamental Algorithms**

Hi! This is my Evidence 1 project for *TC1031 - **Data Structures and Fundamental Algorithms**.

The program reads log files, sorts them using different sorting algorithms, lets you search for records by date and time, and saves the sorted file.

You only need: VS Code, C++20, clang++, Code Runner extension in VS Code
The project already includes the data files.

## How to run it
You can either 
Open the project folder in VS Code, then open src/main.cpp, click **Run Code** at the top in the right corner.

And the program should start in the terminal.

or

If you prefer using the terminal:

Go to the src folder writing:

cd src

Then compile the program with:

clang++ -std=c++20 main.cpp Log.cpp -o main

And you can run it with
./main


## How the program works

Once the program starts:

1. Choose one of the two log files.
2. Choose a sorting algorithm.
3. Enter your estimated sorting time and explain why.
4. The program sorts the records and shows the results.
5. Enter a start and end date/time to search for the specific Logs that we want.
6. The program shows the records found.
7. The sorted records are saved automatically in output607.txt
8. You can choose to run another test or not.
9. The program close


You can choose between:
- Insertion Sort
- Quick Sort
- Merge Sort
- Bubble Sort
- Selection Sort
- Swap Sort


The sorted results are saved in:  output607.txt
